# repogcc

Repositorio base para proyectos y prácticas desarrollados en C/C++ y compilados con [GCC](https://gcc.gnu.org/).

## Requisitos

- GCC o G++
- GNU Make (opcional)

## Compilación básica

Para compilar un archivo C:

```bash
gcc -Wall -Wextra -O2 programa.c -o programa
./programa
```

Para compilar un archivo C++:

```bash
g++ -Wall -Wextra -O2 programa.cpp -o programa
./programa
```
